# Study Center — вход, регистрация и админ-панель

Тёмная страница входа (как на скрине), регистрация студентов и **админ-панель**,
где ты видишь всех, кто зарегистрировался и заходил: имя, логин, **пароль**, email,
время регистрации и журнал входов.

## Страницы
- `/` — вход (Log in)
- `/register` — создать аккаунт (Create new account)
- `/welcome` — экран после входа
- `/admin` — панель директора/админа (защищена паролем)

---

## Как запустить локально
```bash
npm install
npm run dev
```
Открой http://localhost:3000 — вход, а http://localhost:3000/admin — панель.
Пароль админа локально по умолчанию: **admin123**.
Локально данные сохраняются в файл `.data/db.json`.

## Деплой на Vercel (2 варианта)

### Вариант A — через сайт Vercel (проще всего)
1. Залей папку проекта на GitHub (новый репозиторий).
2. Зайди на https://vercel.com → **Add New… → Project** → выбери свой репозиторий.
3. Framework определится автоматически как **Next.js**. Нажми **Deploy**.

### Вариант B — через терминал
```bash
npm i -g vercel
vercel        # первый деплой (ответь на вопросы)
vercel --prod # продакшн
```

## ВАЖНО: общая база данных (чтобы видеть ЧУЖИЕ аккаунты)
На Vercel файловая система временная, поэтому для общей базы нужен Upstash Redis
(бесплатный тариф хватает с запасом):

1. В проекте на Vercel: вкладка **Storage** (или **Integrations → Upstash**) →
   создай базу **Upstash for Redis** и подключи к проекту.
   Vercel сам добавит переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
   (Или создай базу на https://upstash.com и скопируй REST URL + REST TOKEN вручную
   в **Project → Settings → Environment Variables**.)
2. Там же добавь переменную **ADMIN_PASSWORD** = твой пароль для входа в `/admin`.
3. Нажми **Redeploy**, чтобы переменные применились.

После этого все регистрации и входы пишутся в общую базу, и ты в `/admin` видишь всех.

---

## Как это работает
- Студент открывает сайт → **Create new account** → регистрируется.
- Или входит через **Log in**.
- Каждая регистрация/вход пишется в базу.
- Ты заходишь на `/admin`, вводишь ADMIN_PASSWORD и видишь таблицу всех аккаунтов
  (с логинами и паролями) и журнал активности.

## ⚠️ Про безопасность
Пароли хранятся и показываются в открытом виде — так ты и просил. Поэтому:
- предупреди студентов **не использовать** тут пароли от других сервисов;
- держи `ADMIN_PASSWORD` в секрете и поменяй значение по умолчанию.
